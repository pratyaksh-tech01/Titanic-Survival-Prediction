**Titanic Survival Prediction**
Project Objective
Build a Machine Learning model to predict passenger survival on the Titanic dataset.

**Tools Used**
1. Python
2. Pandas
3. NumPy
4. Matplotlib
5. Seaborn
6. Scikit-Learn
7. Google Colab
8. Machine Learning Model
9. Random Forest Classifier

**Model Accuracy = 82.68%**

**Key Insights**
1. Female passengers had a much higher survival rate.
2. First-class passengers survived more frequently.
3. Third-class passengers had the highest mortality rate.
4. Age and Embarked columns contained missing values.
5. Random Forest achieved 82.68% accuracy.
